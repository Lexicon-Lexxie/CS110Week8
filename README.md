# Music Reference Hub (CS110 Week 8)

Team: Awayzo | Team Lead: Lexxie
A simple Windows music player where you can play songs, save reference links, and export notes.

## Where to find each requirement

**R1 (Define the user and utility):** You can find our story brief (user, problem, useful result, limits, privacy boundary and assumption) in `StoryBrief.md`, located in the `8A` folder inside the `Evidence` folder.

**R2 (Prototype and map the events):** You can find our whiteboard logic chart and interface sketch in the `8A` folder inside the `Evidence` folder (`Whiteboard 7a.jpg`). The Discord screenshot showing the whiteboard next to the running app is in the same folder.

**R4 (Validate, recover and save text):** The checks and error recovery for links, files, and notes export/reopen are in `MainWindow.xaml.cs`, inside the `MusicReferenceHub` folder.
